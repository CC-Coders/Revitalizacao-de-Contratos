
# Arquitetura de Geração e Edição do Documento
 - A Solicitação irá manter uma cópia do .docx com os Valores não Preenchidos, e o Jurídico irá fazer a alteração em cima desse documento
 - Um segundo documento será gerado com os Valores Preenchidos, isso para que caso essa solicitação seja retornada para Edições, o modelo alterado pelo Jurído ainda esteja em Branco, aceitando receber os Novos Valores alterados
